# About me

I’m passionate about building functional and well-structured solutions, whether for web, mobile, or more complex systems like chatbots. I’ve worked on various academic and personal projects that have allowed me to strengthen both my technical and teamwork skills.

Wizeline

In collaboration with Wizeline, I developed a web platform designed to help users discover artificial intelligence tools, categorized by functionality (text, image, video, etc.). I used HTML, CSS, JavaScript, Node.js, Express, and PostgreSQL to build a fully functional platform featuring category filters, detailed descriptions, and helpful links. I implemented a database to store tool information and created the logic needed to perform queries and display personalized results. The platform improved accessibility and understanding of the wide range of AI tools available online. Users were able to quickly find tools relevant to their needs, helping them save time and make better technology adoption decisions.

Banco de Alimentos de Guadalajara

I designed a mobile application to facilitate clothing donations and promote solidarity among users in a secure and organized way. The app was developed using SwiftUI for the interface and integrated with Firebase Authentication and Firestore to manage users and store data. Key features included user registration, login, and the option to donate clothes anonymously or with an authenticated account, along with security measures to protect users’ personal information. Although the project was not deployed in production, the application demonstrated a strong focus on user experience and data protection. It was well received in academic evaluations and highlighted the potential of mobile solutions for social causes.

Oracle

I am currently working on a Telegram chatbot that is part of a task management system in a collaborative environment. The goal is to improve communication between a Project Manager and a team of developers. The chatbot is integrated with Oracle Cloud Infrastructure and Oracle Database, and I’m using Java, React, C++, and GitHub as core tools. I have focused on implementing a new feature that allows the bot to create and assign tasks automatically, notifying the assigned developers via Telegram. This project has allowed me to apply my knowledge in service integration, process automation, and cloud database management. The implementation of this new feature directly contributes to improved team productivity and streamlines the overall workflow.
